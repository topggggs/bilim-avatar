# Работающий локальный стенд

```bash
npm ci
npm run build
npm run preview:local
```

Открыть http://127.0.0.1:53001. Нужен запущенный Docker. Команда сама поднимает PostgreSQL, Redis и S3, создаёт приватный bucket, добавляет вымышленных пользователей только в пустую БД, запускает API и воркер. Секреты генерируются локально в `.data/preview-secrets.env` с правами 0600; они не попадают в Git. Ранее созданные данные сохраняются.

Вход: «Посмотреть демо». Регистрация по почте/телефону тоже работает: показываются явно помеченные тестовые ссылка/код. Новые оригинальные герои: раздел «Персонажи», пять вселенных, четыре архетипа, смена палитры и образа. Кнопка выбора переносит внешность в создание профиля; архетип по-прежнему определяется результатами теста.

На этом стенде нет внешних писем/SMS и персональной генерации Images API. Аватары — оригинальные SVG. Доступов к SMTP, Twilio, Bilim OIDC и платной модели в текущем окружении нет. Их подключение предусмотрено production-переменными `.env.example`; ключи и утверждённые параметры должны быть выданы владельцами соответствующих сервисов. Публичный домен/сервер этим локальным запуском не создаётся.

`/api/ready` показывает готовность БД, очереди и воркера. В админской роли блок «Подключения» явно различает локальные сервисы и demo/fallback. Реальный сотрудник вне demo после регистрации получает pending, пока администратор не подтвердит доступ.

Ctrl+C останавливает API и worker. Docker-сервисы и тома остаются для следующего запуска. Остановка инфраструктуры без удаления данных:

```bash
docker compose --env-file .data/preview-secrets.env -f compose.preview.yml stop
```

Не используйте `down -v` для обычной остановки: это удаляет локальные данные. Не открывайте demo-порт в Интернет.
