# План развития Bilim

16 октября 2026. Платформа развития сотрудников BI Academy.

## Сделано в текущем обновлении

1. **Стиль BI Group:** сине-белая палитра, верхняя навигация, большой архитектурный баннер, округлые карточки, адаптивная шапка. Визуальный ориентир — [официальный сайт BI Group](https://bi.group/ru). Существующие тест и роли сохранены.
2. **Главная:** три переключаемых баннера, быстрый вход в тест, собственный профиль и следующий шаг. Проценты берутся из результата сотрудника, до теста показаны прочерки.
3. **Мой маршрут:** Bilim → BuildEX → BIU → KPI, рекомендованный этап и персональные рекомендации с переходом в настроенный учебный портал. Этапы не выдаются за пройденные курсы; для фактического прогресса нужна LMS-интеграция.
4. **Команда:** поиск по имени/должности, фильтр наличия профиля. Серверное ограничение доступа своей командой действует до фильтрации.
5. **Минимум текста:** нет декоративных стикеров и лишних значков. Длинные пояснения открываются по нажатию.

6. **Ранги:** Старт → Практик → Специалист → Эксперт → Наставник. После теста доступны практики: сотрудник описывает результат, руководитель подтверждает или возвращает на доработку. Ранг и прогресс сохраняются и видны в профиле, маршруте и команде. Проценты самооценки на ранг не влияют.
