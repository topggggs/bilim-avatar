# Проверка · 17 октября 2026

Проект заменён исходниками из `bilim-avatar-main.rar`, затем добавлен [письменный тест v0.2.0](written-assessment.md). Проверка на Node.js 26, Chromium, PostgreSQL 17 и Redis 7.

- **131 тест прошёл**, 1 S3 integration пропущен без отдельного тестового S3. Проверены старый числовой расчёт, новая рубрика, отдельные оценки вопроса 15, валидация текста и ответа модели, права, регистрация, восстановление, ранги, PostgreSQL и Redis.
- **Покрытие ядра:** statements/functions/lines — 100%, branches — 99.24%. Включены `written.ts`, прежний scoring и buildAvatar.
- **14 Playwright-сценариев прошли** на production-сборке: письменные ответы, минимум символов, offline/reload без потерь, автосохранение, анализ через серверный адаптер с тестовой фикстурой провайдера, выбор при равных качествах, профиль, приватность команды, 90 дней, ранги, настройка аватара, три языка, светлая/тёмная тема, регистрация по почте/SMS и восстановление.
- Проверены мобильные экраны 375px, отсутствие горизонтального переполнения, автоматический axe WCAG 2/2.1 AA на тесте и основных страницах.
- PostgreSQL сохраняет письменные ответы, модель, версию рубрики, отчёт и результат после закрытия и повторного подключения. Старая история сохраняется; миграция файлового снимка отдельно проверена.
- Повторный submit не запускает вторую модель; выбор героя использует готовый отчёт. Ошибка/отказ/неполный JSON/неверные оценки не создают профиль. Ответы сохраняются, повтор явный; зависшая метка запуска восстанавливается.
- TypeScript, production-сборка, Prettier и `git diff --check` проходят. `npm ci --ignore-scripts` по lock-файлу: 0 найденных уязвимостей.

**Добавлен Gemini:** выбран серверный провайдер `gemini`, адаптер проверяет JSON-отчёт, блокировку ответа и тайм-ауты, ключ передаётся заголовком без URL и перенаправлений. Согласие привязано к провайдеру и сохраняется в БД; смена сервиса требует повторного согласия.

**Живой Gemini проверен 17 октября 2026:** добавленный ключ принят Google; полный анализ 15 синтетических ответов через `npm run ai:check` завершился успешно на `gemini-3.8-flash`. Получены и проверены 16 оценок и четыре процента. При первом вызове исправлен REST-параметр `responseFormat.text.mimeType`: требуется enum `APPLICATION_JSON`, а не строка MIME. Ключ хранится только в игнорируемом `.env`. В unit/REST/E2E используются явно названные тестовые фикстуры; реальный запрос проверен отдельно на синтетических примерах. В обычном приложении при отсутствии ключа сохранение работает, а анализ возвращает понятное сообщение о неподключённом сервисе. Настройка — `GEMINI_API_KEY`, `ANALYSIS_PROVIDER=gemini` и `GEMINI_MODEL` на сервере. Проверка — `npm run ai:check`, затем перезапуск API.

Реальные SMS, письма, Bilim SSO, Images API и внешние учебные порталы в этом прогоне не вызывались. Safari/Samsung Internet, старые мобильные ОС, нагрузки и валидность методики требуют отдельной приёмки.

Повторение:

```bash
npm ci
npm run test:coverage
npm run build
npx playwright install chromium
npm run test:e2e
```

Для PostgreSQL/Redis задать `TEST_DATABASE_URL` (строго отдельная БД `bilim_test`) и `TEST_REDIS_URL`. E2E-провайдер находится только в `tests/fixtures/e2e-server.ts`, production entry point его не импортирует. При выключенной инфраструктуре три соответствующих теста пропускаются.
